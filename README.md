# CRUD API For A Resource

A RESTful CRUD API built with Node.js, Express, and MongoDB (Mongoose).

## Setup & Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env`:
   ```env
   MONGO_URI=your_mongodb_connection_string
   ```
3. Start the server:
   ```bash
   node sever.js
   ```
